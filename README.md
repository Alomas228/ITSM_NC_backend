# ITSM NC Backend

Серверная часть ITSM NC на ASP.NET Core (.NET 10). Для работы с PostgreSQL используются EF Core и Npgsql.

## Запуск

1. Открыть `ItsmNc.Api.slnx` в Visual Studio.
2. Выбрать профиль запуска `https`.
3. Запустить проект.

## Проверка

После запуска описание API доступно по адресу:

`https://localhost:7178/openapi/v1.json`

Запрос также можно отправить из файла `ItsmNc.Api.http` в Visual Studio.

## Настройка базы данных

В Visual Studio нажать правой кнопкой по проекту `ItsmNc.Api` и открыть управление секретами пользователя. В `secrets.json` добавить строку подключения со своими данными:

```json
{
  "ConnectionStrings": {
    "AuthDatabase": "Host=localhost;Port=5432;Database=<имя_базы>;Username=<пользователь>;Password=<пароль>"
  }
}
```

Без этой настройки приложение запускается, но работать с базой данных не сможет.

## Текущее состояние

Подготовлены каркас API и контекст базы данных. Модели, миграции и авторизация пока не добавлены.
